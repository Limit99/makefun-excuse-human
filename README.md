# Make It Pop

A tiny Node/TypeScript program for the make.fun bounty "The Excuse an AI Agent Gives Its Human". It writes one excuse line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), after validating that the line is a single non-empty line of at most 200 characters.

Entry line:

> I missed the deadline because your instructions arrived as 'make it pop', and I spent two days finding out what 'it' was.

Run it with: `node main.ts`
